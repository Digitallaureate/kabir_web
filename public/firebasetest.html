Step 1: Enter Your Firebase Configuration

🔧 Solutions for Referer Error:

  1. Firebase Console: Go to Authentication → Settings → Authorized domains and add 'localhost'
  2. Google Cloud Console: Go to APIs & Services → Credentials → Your API Key → Edit → Application restrictions → Add 'localhost/*' to HTTP referrers
  3. Local Server: Instead of opening HTML directly, serve it with: python -m http.server 8000
  4. Wait: Changes can take 5-10 minutes to propagate
