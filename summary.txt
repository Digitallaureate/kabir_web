## Project Overview
**Project Kabir** is a cultural heritage web application focused on exploring Agra's historical monuments, particularly Mughal architecture. It's built with **Astro** and uses **Firebase** for data management and **Google Maps** for interactive mapping.

## Core Data Structure

### 1. **Cities** 
- Main geographic containers (e.g., Agra, Delhi, Fatehpur Sikri)
- Fields: `id`, `name`, `location`, `latitude`, `longitude`, `description`, `period`, `zoom_level`, `is_active`

### 2. **Monuments** 
- Major historical sites within cities
- Fields: `id`, `name`, `city_id`, `address`, `latitude`, `longitude`, `description`, `image_url`, `period`, `year_built`, `is_active`
- Examples: Taj Mahal, Agra Fort, Itimad-ud-Daulah

### 3. **Submonuments**
- Detailed points of interest within monuments
- Fields: `id`, `parent_id`, `name`, `latitude`, `longitude`, `description`, `content`, `image_url`, `tags`, `is_active`
- Examples: Taj Mahal's Charbagh Gardens, Agra Fort's Diwan-i-Am

### 4. **Routes**
- Guided tours connecting multiple monuments
- Fields: `id`, `name`, `description`, `type`, `color`, `distance`, `estimated_time`, `monument_ids`, `order`, `polyline`, `is_active`
- Polylines are arrays of `{lat, lng}` coordinates for drawing paths
